# AutoCRM

AutoCRM — це комплексна інформаційна система для спрощення та автоматизації управління замовленнями автосервісу. Проєкт реалізовано на базі monorepo-архітектури з використанням сучасних технологій, зокрема штучного інтелекту для інтелектуального пошуку та аналізу даних.

## Налаштування та запуск (Setup)

### Передумови (Prerequisites)

Якщо у вас не встановлено Node.js та pnpm:
1. **Node.js (рекомендовано версію 22)**: Завантажте інсталятор v22 з [офіційного сайту Node.js](https://nodejs.org/) або встановіть через `nvm`:
   ```bash
   nvm install 22
   nvm use 22
   ```
2. **pnpm**: Після встановлення Node.js виконайте команду в терміналі:
   ```bash
   npm install -g pnpm
   ```

### 1. Локальна розробка (Рекомендовано)
У цьому режимі бази даних працюють у Docker, а фронтенд та бекенд запускаються локально для швидкої розробки.

1. **Встановлення залежностей**:
   ```bash
   pnpm install
   ```
2. **Запуск баз даних та налаштування БД** (потрібен запущений Docker):
   ```bash
   pnpm run setup
   ```
3. **Запуск застосунку**:
   ```bash
   pnpm run dev
   ```
   Після цього застосунок буде доступний за адресою [http://localhost:5173](http://localhost:5173).

---

### 2. Повний запуск у Docker (Автоматичний / Тестовий)
Якщо ви хочете запустити всю систему (включаючи фронтенд та бекенд) виключно в Docker-контейнерах.

#### Перший запуск (білд образів + seed бази даних)
```bash
pnpm run dev:docker:build
```
Ця команда збере Docker-образи, створить таблиці та наповнить базу тестовими даними.

#### Наступні запуски (без перебілду)
```bash
pnpm run dev:docker
```
Запускає вже зібрані контейнери. Seed автоматично пропускається, якщо база вже містить дані.

> **Після змін у коді** запускайте `dev:docker:build` для перебудови образів.

#### Варіант з усіма сервісами (включаючи Unstructured API)
```bash
pnpm run dev:docker:full
```

Після завершення запуску застосунок буде доступний за адресою:
- Фронтенд: [http://localhost](http://localhost) (порт 80)
- Бекенд API: [http://localhost:4200/api](http://localhost:4200/api)
