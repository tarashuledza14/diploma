# AutoCRM

AutoCRM — це комплексна інформаційна система для управління замовленнями автосервісу. Проєкт побудований на базі мікросервісної/монорепозиторної архітектури (pnpm workspace) та інтегрує технології штучного інтелекту (LangChain, Qdrant) для обробки даних, забезпечуючи швидку взаємодію в режимі реального часу.

## 🏗 Архітектура проєкту

Проєкт організовано як monorepo за допомогою **pnpm workspaces**. Він складається з двох основних частин:

- **Frontend** (`packages/frontend`): Клієнтська частина.
- **Backend** (`packages/backend`): Серверна частина та бізнес-логіка.

### Технологічний стек

**Frontend:**
- **Фреймворк:** React 19 + Vite + TypeScript
- **Управління станом:** Zustand, TanStack React Query
- **Стилізація:** Tailwind CSS 4, shadcn/ui, Radix UI
- **Роутинг:** React Router v7
- **Інше:** Socket.io-client (для real-time взаємодії), react-hook-form + zod (валідація), i18next (багатомовність)

**Backend:**
- **Фреймворк:** NestJS + TypeScript
- **База даних:** PostgreSQL (з ORM Prisma)
- **Векторна база даних:** Qdrant
- **AI / LLM інтеграція:** LangChain, LangGraph, OpenAI API (для RAG та розумного пошуку/аналізу)
- **Зберігання файлів:** AWS S3
- **Інше:** Socket.io (real-time події), JWT (авторизація), Nodemailer (відправка пошти), обробка PDF (unstructured-api)

## 🚀 Розгортання проєкту

### Передумови
Перед початком переконайтеся, що на вашому комп'ютері встановлено:
- **Node.js** (рекомендовано версію 20+)
- **pnpm** (встановлюється командою `npm install -g pnpm`)
- **Docker** та **Docker Compose** (наприклад, Docker Desktop) для запуску баз даних.

### 1. Встановлення залежностей
Відкрийте термінал у кореневій папці проєкту та виконайте:
```bash
pnpm install
```

### 2. Ініціалізація інфраструктури
Для розгортання необхідних сервісів (PostgreSQL, Qdrant) у Docker, виконання міграцій бази даних та наповнення її початковими даними (seeding), виконайте:
```bash
pnpm run setup
```
*(Примітка: Якщо вам також потрібен сервіс для парсингу неструктурованих даних `unstructured-api`, використовуйте команду `pnpm run setup:full`).*

### 3. Запуск застосунку
Для одночасного запуску клієнтської та серверної частин у режимі розробки виконайте:
```bash
pnpm run dev
```

### 4. Доступ до системи
Після успішного запуску відкрийте веб-оглядач та перейдіть за адресою:
[http://localhost:5173](http://localhost:5173)

## 📜 Основні скрипти (Scripts)

У кореневому `package.json` доступні такі команди:

- `pnpm run dev` — одночасний запуск backend та frontend у режимі розробки.
- `pnpm run build` — збірка обох пакетів для продакшену.
- `pnpm run setup` — підняття docker-контейнерів, push схеми Prisma та запуск seed-скрипту.
- `pnpm run setup:full` — те ж саме, але з додатковим контейнером `unstructured-api`.
- `pnpm run backend` — запуск лише бекенду.
- `pnpm run frontend` — запуск лише фронтенду.
- `pnpm run prisma:seed` — примусовий перезапуск сідеру бази даних.
