# AutoCRM

AutoCRM — це комплексна інформаційна система для спрощення та автоматизації управління замовленнями автосервісу. Проєкт реалізовано на базі monorepo-архітектури з використанням сучасних технологій, зокрема штучного інтелекту для інтелектуального пошуку та аналізу даних.

## Налаштування та запуск (Setup)

### Передумови (Prerequisites)

Якщо у вас не встановлено Node.js та pnpm:
1. **Node.js (рекомендовано версію 22)**: Завантажте інсталятор v22 з [офіційного сайту Node.js](https://nodejs.org/) або встановіть через `nvm`:
   ```bash
   nvm install 22
   nvm use 22
   ```
2. **pnpm**: Після встановлення Node.js виконайте команду в терміналі:
   ```bash
   npm install -g pnpm
   ```

### 1. Встановлення залежностей
Виконайте команду в кореневій папці проєкту:
```bash
pnpm install
```

### 2. Ініціалізація інфраструктури
Переконайтеся, що запущено Docker, та виконайте команду для підняття контейнерів і налаштування бази даних:
```bash
pnpm run setup
```

### 3. Запуск у режимі розробки
Для одночасного запуску серверної та клієнтської частин виконайте:
```bash
pnpm run dev
```

Після запуску застосунок буде доступний за адресою [http://localhost:5173](http://localhost:5173).
